# Archivo

`archivo-latin-var.woff2` is the **Archivo** variable font (latin subset; axes
`wght` 100-900 and `wdth` 62-125), Sleeve's interface typeface.

- Designer: Omnibus-Type (Hector Gatti and the Omnibus-Type team)
- Source: Google Fonts (Archivo v25, latin subset). Upstream:
  <https://github.com/Omnibus-Type/Archivo>
- Licence: SIL Open Font License, Version 1.1 (OFL). Free to use, bundle and
  redistribute with software; the font may not be sold on its own. The full
  licence text is at <https://openfontlicense.org/>.

This file travels with the font as the OFL asks. The font is bundled unmodified.
